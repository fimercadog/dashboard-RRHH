# VERTICAL_TEMPLATE — Plantilla de vertical

1. Leer CLAUDE.md, CORE_CONTRACT.md, MEMORY.md, DEVELOPMENT_MEMORY.md, CORE_INHERITANCE_REGISTRY.md, DEFINITION_OF_DONE.md y SPEC.md.
2. En tareas no triviales, ejecutar Find Skills y leer las skills relevantes. Para programación no trivial, ejecutar Graphify antes de modificar código.
3. Especificar alcance, fuera de alcance, datos, permisos, dependencias, riesgos y aceptación.
4. Confirmar la BD real antes del backend; alinear modelos, relaciones, requests, policies, services, resources y rutas.
5. Reutilizar componentes CORE; cumplir UX_FORM_RULES.md.
6. Verificar pruebas, build/typecheck/lint, permisos, aislamiento, E2E y regresión según el alcance.
7. Registrar decisiones y evidencia; promover patrones transversales al CORE.

Clasificar cada hallazgo como CORE reutilizable, específico de vertical, configurable o pendiente de decisión. No modificar CORE por una necesidad exclusiva de una vertical. No declarar DONE por la sola presencia de código o documentación.
