# DEFINITION_OF_DONE

- IMPLEMENTADO: code exists.
- VERIFICADO: relevant automated checks passed with evidence.
- E2E VERIFICADO: critical end-to-end flows passed in a real browser or equivalent.
- DONE / LISTO PARA USUARIO: acceptance criteria, independent review, relevant regression, documentation and in-scope deployment checks are complete.

IMPLEMENTADO != VERIFICADO != E2E VERIFICADO != DONE.

Never claim a test passed unless it was executed. Report tests not run. Documentation is not proof of runtime behavior.

Before closing, review data model, tenant scope, permissions, domain services, frontend states, responsive behavior, tests, build/typecheck/lint when relevant, documentation references, CORE inheritance and deployment evidence when deployment is in scope.
